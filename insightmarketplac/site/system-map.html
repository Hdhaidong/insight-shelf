一、四层架构（自下而上）

每一层只依赖下一层、为上一层供给——同一套数据与流程贯穿四层，这是各业务线结论能互相咬合的原因。能力流向：硬件算力 → 智能体产能 → 平台沉淀 → 服务交付。

Layer 01 · 底座

硬件层

Agent 硬件与边缘算力——给智能体造身体，给数据上锁。

  • 能力：工业与无线网关（Modbus / CAN / BLE / LoRa），端侧本地推理
  • 边界：物理 Approve 门禁 + 可拔插加密隐私卡
  • 用途：数据不出域的客户场景，分析跑在端侧
Layer 02 · 产能

智能体层

研究与运营数字员工——替人跑研究腿，不做聊天窗口。

  • 产能去向：数据洞察线的分析结论与数据 token
  • 闭环：token 装回 Agent，数据养 Agent、Agent 产出数据
  • 方式：多源采集 + 交叉验证 + 人工研判，结论可复核
Layer 03 · 平台

系统层

自有商业平台——业务在系统里沉淀为客户资产。

  • 规模：12 个业务分区、62 个页面，覆盖客户全生命周期
  • 底座：ERP / WMS / CRM 与智能体交付都跑在这一层
Layer 04 · 交付

服务层

面向客户的交付形态——七大业务线，独立交付、按阶段组合。

  • 七线：渠道入驻 · 数据洞察 · 系统工具 · 品牌增长 · 众筹分销 · 合规企业 · 展会服务
  • 交付物：入驻方案 · 数据结论与 token · 系统部署 · 内容与增长 · 展期执行

二、七大服务线 × 三条主线

每张卡片是一条可独立交付的业务线，卡片底部是直达入口。三条主线：渠道（入驻·代理·展会·合规）、数据（分析·Token·洞察·雷达）、内容（红人·短剧·众筹·系统）。

四、合作模式与收费结构

三种合作模式可逐步升级：多数伙伴从 OEM 起步，产品成熟叠 ODM，品牌就绪升 OBM——同一张渠道网络，每步利润更深。

Model 01

OEM · 来图代工

  • 设计：买方图纸（金样封存）
  • 备货：无需海外仓
  • 物流：工厂交货，我司接管
  • 利润：制造利润
  • 特点：库存买断、PO 结算、不收服务费——最快首单
Model 02

ODM · 选款贴牌

  • 设计：供应商自有设计 IP
  • 备货：海外仓入仓
  • 物流：海外仓本地发货
  • 利润：设计 + 制造
Model 03

OBM · 品牌出海

  • 设计：品牌全链路自有
  • 备货：备货 + 品牌授权
  • 物流：协同仓配网络
  • 利润：制造 + 品牌溢价
Included Free · 7 项

非收费项（任何合作均含）

  • 渠道账号开设（20+ 平台开户搭建）
  • Agent 智能客服
  • 账号安全维护（风控申诉）
  • 数据周报（销售/库存/广告）
  • 红人资源对接
  • 内容素材库
  • 专属对接人（1 工作日响应）
Per-Item Fees · 6 项

收费项次（注册后解锁报价）

服务项计费方式
联合运营（选品/定价/广告）按销售额分成，比例按品类评估；或项目制全包
端到端仓配履约按实际成本（头程+仓储+尾程）· 99.8% 当日出库
红人营销投放固定费 / 佣金分成 / 混合，按投放案件报价
网剧 / AI 短剧定制按项目报价
Agent / ERP 定制开发按需求评估报价
数据订阅（六条订阅线）按订阅线与周期计费
注册机制：注册免费——注册前见全部业务介绍与计费方式；注册后解锁逐项单价与分成比例，报价单（含品类评估）1 个工作日内发送。OEM 库存买断不收任何服务费。
