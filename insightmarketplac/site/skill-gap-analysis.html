Section 02 · Mapping Frame

二、映射框架：三路径 × 七服务线

沿用业务梳理报告的结论框架——三条客户路径是客户视角的入口，七大服务线是交付视角的底座。技能库的映射先看路径支撑度，再看逐线弹药。

客户路径依赖服务线技能支撑度一句话判断
A · 工厂出海
渠道 × 合规 × 系统		渠道入驻 + 系统工具 + 合规与企业 + 展会服务中渠道数据覆盖 29%，本地工作流是「业务 Agent 工具」的实证样板；合规 / 展会为零但属低频人工环节
B · 品牌增长
洞察决定打哪里，声量打出复利		品牌增长 + 数据洞察前重后轻洞察与声量监测充足；执行侧红人匹配 / 短剧制作 / 产品视觉三个缺口叠加
C · 数据与分销
数据先行，动作跟上		数据洞察 + 众筹分销强选品 / 定价 / 消费者 / 竞品四线弹药充足；补上众筹信号线即闭环
路径即漏斗的技能含义：路径 C 的数据能力同时服务 A 的选品与 B 的声量决策——技能库「选品 + 数据双主力」的结构，恰好是三条路径共享的公共底座；而三条路径各自独占的环节（A 的合规、B 的内容制作、C 的众筹信号），正是缺口集中区。

Section 04 · Six Data Lines

四、数据订阅六线深查

数据洞察线是订阅业务的主战场——按六条订阅线逐一核对技能弹药。结论：四强、一中、一零。

订阅线技能支撑覆盖度代表技能缺口
选品约 35强潜力商品筛选、类目市场研究 / 实时 / 历史报告、历史商品筛选、Keepa 搜索、相似商品特征、1688 以图搜款 / 同款货源、多平台商品池抓取—
定价约 15强Keepa 历史趋势、商品历史趋势（Amazon / Walmart / Shopee）、优惠券趋势、DealWatch 促销监控、多平台价格带抓取—
消费者约 18强VOC 全家桶（评论洞察 / VOC 分析 / 列表 / 抓取）+ Reddit 舆情 + 小红书内容趋势 + B 站三件套 + YouTube 评论小语种 VOC 覆盖待验证
竞品约 20强竞品列表 / 竞品关键词 / 竞品情报监控、ASIN 关键词反查 / 流量词反查 / 关联流量 / 流量结构 / 流量来源、关键词流量竞争Walmart 竞品关键词仅 3 个，纵深不足
众筹信号0零间接可用：Google 搜索 / SERP、Reddit 舆情、X 抓取（热度侧写，非众筹平台原生数据）Kickstarter / Indiegogo 数据源为零——P0 缺口
品牌声量约 10中FB 广告库素材、IG 内容、X 推文、YouTube 评论、Google SERP / Trends、小红书 / 抖音缺聚合与情感分析工作流（可由本地工作流补）
最痛的一格：「众筹信号」是六线中唯一零自动化的订阅线，而它同时是 radar 众筹雷达周报与「提前半年看需求」叙事的数据底座——当前全靠人工。补齐一个 Kickstarter / Indiegogo 数据技能，六线即全部闭环。

Section 06 · Gap Register

六、缺口清单与补齐优先级

11 项缺口按「对主营叙事的杀伤力」排序：P0 直接影响在售叙事，P1 覆盖缺口明显，P2 长尾补强。

P0 · 直接影响主营叙事（3 项）

Gap 01 · P0

众筹平台数据

Kickstarter / Indiegogo（可延展 Makuake、Campfire）的商品 / 融资 / 进度数据。

杀伤点：「众筹信号」订阅线与 radar 众筹雷达周报当前零自动化、全靠人工。

Gap 02 · P0

TikTok Shop 数据

商品 / 店铺 / 达人带货数据。

杀伤点：渠道墙成员 + 77 平台页在列 + 内容电商主战场；抖音技能无法覆盖海外版，与红人主线也互相卡位。

Gap 03 · P0

产品视觉类技能

Listing 主图 / A+ 内容 / 视频脚本 / 品牌素材生成。

杀伤点：品类计数 0；路径 B 的执行侧刚需，且是「品牌增长」从洞察走向交付的最后一公里。

P1 · 覆盖缺口明显（4 项）

Gap 04 · P1

红人发现与管理

达人库检索 / 匹配 / 报价 / 排期。

影响：红人营销是三大主线之一，技能库现无任何直接支撑（Instagram 抓取最接近但非达人库）。

Gap 05 · P1

欧洲主流渠道数据

Otto / Allegro / eBay / 法国系（Carrefour / Cdiscount / Fnac）。

影响：渠道墙与入驻页在列、数据为零；现有 Bol / Kaufland / Zalando 抓取证明欧洲数据可得。

Gap 06 · P1

线下零售数据

Sam's Club / Costco / Macy's / Kohl's / Kroger。

影响：5 个渠道墙成员零数据；可用第三方货架扫描类数据源替代。

Gap 07 · P1

AI 短剧 / 内容制作执行

脚本 / 分镜 / 成片工作流。

影响：路径 B 核心交付物（AI 短剧定制）无技能化支撑，服务交付全靠人工排期。

P2 · 长尾补强（4 项）

Gap 08 · P2

展会情报技能

日程 / 参展商 / 买家名录。展会服务线纯人工；radar 展会档期手工维护。

Gap 09 · P2

合规流程技能

商标查重 / VAT 测算 / 注册状态查询。合规线纯人工，属可接受的低频环节。

Gap 10 · P2

跨平台 Listing 分发

多平台批量上架 / 同步 / 合规校验。现仅 Amazon 标题合规 1 个技能。

Gap 11 · P2

ERP / WMS / CRM 对接

订单 / 库存 / 客户数据同步类技能。系统工具线从演示走向生产的关键一步。

Section 07 · Verdict

七、结论与补齐路线

一句话总评：选品与数据引擎已经成型，品牌与内容执行等待补装。

  • 路径 C 数据与分销——弹药充足。选品 / 定价 / 消费者 / 竞品四线强覆盖，多平台广度（4 大洲 38+ 平台）是现成差异化；补齐众筹信号即六线闭环，这是性价比最高的一步棋。
  • 路径 A 工厂出海——够用但不厚。渠道数据覆盖 29%、合作渠道 58%；Amazon / Walmart / Shopee 三平台纵深可用，本地工作流是「业务 Agent 工具」的实证样板；扩欧洲渠道数据即可放大。
  • 路径 B 品牌增长——前重后轻。洞察与监测能力够，但红人匹配 / 短剧制作 / 产品视觉三个执行缺口叠加——下一步的主战场在这里，也是技能市场本身的产品视觉 = 0 所揭示的行业空位。
  • 结构性风险两条：工具方集中度 66%（双源备份）；「分析类 129 个 vs 执行类 2 个」的失衡——执行类（视觉 / 制作 / 投放 / 分发）全是自建机会。
