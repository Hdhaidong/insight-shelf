System Architecture

One continuously evolving system — the complete map

FactoryToShelf is not a collection of projects — it's a single system growing from the bottom up: the hardware layer provides compute and physical boundaries, the agent layer produces intelligence, the platform layer accumulates it into systems, and the service layer delivers it to clients — connecting China's manufacturing capability to US channels and the content ecosystem. All four layers share the same foundations: channels, data, and content.

Layer 02 · Production

Agent Layer

AGENTS

Research and operations digital employees that run the research leg for humans — product discovery, competitive intelligence, social listening, automated reporting — built on real e-commerce workflows, not a chat window.

  • Output: the analysis conclusions and data tokens of the Data Intelligence line are produced on this layer
  • Loop: tokens plug back into agents — one sentence pulls a report, agents produce new conclusions; data feeds agents, agents produce data
  • Method: multi-source collection + cross-validation + human review — every conclusion is auditable
  • Interface: natural-language driven — one sentence pulls the assortment, competitor, or brand-voice report
  • Compounding: proven methods harden into reusable skills — agents get sharper with use, and the skills stay when people leave
↑Agent production
Layer 01 · Foundation

Hardware Layer

EDGE · HARDWARE

Agent hardware and edge compute — giving agents a body, and putting locks on data.

  • Capability: industrial and wireless gateways (Modbus / CAN / BLE / LoRa), local on-device inference
  • Boundary: a physical Approve gate on every write; pluggable encrypted privacy card — pull the card and all history leaves with you
  • Use case: for clients whose data must not leave the premises, analysis runs at the edge
Capability flow (bottom-up): hardware compute → agent production → platform accumulation → service delivery. Each layer depends only on the one below and feeds the one above — one dataset, one process, across all four. That's why conclusions from different service lines interlock.

Three Client Paths

Different clients combine the lines differently — these three paths cover 90% of what we do.

Path A

Factory-to-Market

FACTORY → MARKET
Qualification self-audit→ Compliance entities (company / trademark / VAT)→ Onboard 76 platforms→ ERP / WMS / CRM systems→ Meet buyers at shows→ Brand growth transition
For: OEM / ODM factories upgrading from "selling goods into channels" to "running a brand inside channels" — survive year one, have channels coming to you by year three.
Path B

Brand-to-Voice

BRAND → VOICE
Data intelligence (brand baseline)→ Influencer campaigns→ AI short dramas→ Social matrix operations→ Three-layer impact review
For: brands with channels but no voice — insights decide where to hit, influencers and dramas hit it, and the review system turns budget into assets.
Path C

Data-to-Distribution

DATA → DISTRIBUTION
Crowdfunding radar finds products→ Momentum evaluation + angle extraction→ Data tokens into your systems→ Distribution channel placement
For: creators (topic ammunition), sourcing teams (see demand six months early), distributors (position the breakouts) — data first, action follows.
Data discipline (all lines): we deliver data analysis and data tokens — we do not provide, and do not disclose, data sources. You get conclusions and usable data, never our supply chain. A proprietary monitoring network, multi-source cross-validation, and human review — that's how our judgments are made.
