System Architecture

一个持续进化的系统，一图看懂

FactoryToShelf 不是一个项目集合，而是一套自底向上生长的系统：硬件层提供算力与物理边界，智能体层生产洞察，系统层沉淀为平台，服务层把能力交付到客户手里——把中国的供给能力接进美国的渠道与内容生态。四层共享同一套底层：渠道、数据、内容。

Layer 02 · 产能

智能体层

AGENTS

研究与运营数字员工——替人跑研究腿：选品发现、竞品情报、社交聆听、自动报告，长在真实电商工作流上，不做聊天窗口。

  • 产能去向：数据洞察业务线的分析结论与数据 token 由这一层生产
  • 闭环：token 装回 Agent——一句话调出报告，Agent 再生产新结论，数据养 Agent、Agent 产出数据
  • 工作方式：多源采集 + 交叉验证 + 人工研判，每个结论可复核
  • 使用界面：自然语言驱动——一句话调出选品、竞品、声量报告
  • 经验沉淀：熟练方法固化为可复用技能，Agent 越用越准，人走技能留下
↑智能体产能
Layer 01 · 底座

硬件层

EDGE · HARDWARE

Agent 硬件与边缘算力——给智能体造身体，给数据上锁。

  • 能力：工业与无线网关（Modbus / CAN / BLE / LoRa），端侧本地推理
  • 边界：物理 Approve 门禁，每一次写入都过真实开关；可拔插加密隐私卡，拔卡即带走全部历史
  • 用途：数据不出域的客户场景，分析直接跑在端侧
能力流向（自下而上）：硬件算力 → 智能体产能 → 平台沉淀 → 服务交付。每一层只依赖下一层、为上一层供给——同一套数据与流程贯穿四层，这也是各业务线的结论能互相咬合的原因。

三条客户路径

不同客户用不同的业务组合——三条路径覆盖了我们 90% 的服务场景。

路径 A

工厂出海路径

FACTORY → MARKET
资质清单自查→ 合规主体（公司 / 商标 / VAT）→ 76 平台入驻→ ERP / WMS / CRM 系统→ 展会见买家→ 品牌增长转型
适合：OEM / ODM 工厂从「卖货给渠道」升级到「做品牌进渠道」——第一年在渠道里活下来，第三年让渠道来找你。
路径 B

品牌增长路径

BRAND → VOICE
数据洞察（品牌声量摸底）→ 红人营销投放→ AI 短剧定制→ 社媒矩阵运营→ 三层影响复盘
适合：已有渠道但缺声量的品牌方——用洞察决定打哪里，用红人与短剧打出声量，用复盘体系把预算变成资产。
路径 C

数据与分销路径

DATA → DISTRIBUTION
众筹雷达发现新品→ 热度研判 + 卖点拆解→ 数据 token 接入客户系统→ 分销渠道对接
适合：创作者（口播选题弹药）、选品团队（提前半年看需求）、渠道商（爆筹产品分销卡位）——数据先行，动作跟上。
数据纪律（全业务线通用）：我们提供数据分析与数据 token，不提供、也不披露数据源头——你拿到的是结论和可用数据，不是我们的供应链。自有监测网络 + 多源交叉验证 + 人工研判，是我们输出判断的方式。
